# MSCP 용어집

**검토 기준일: 2026-11-03.** 이 문서는 핵심 용어를 한국어로 설명하고 각 레벨의 정의를 연결합니다. 정의의 가정과 세부 조건은 해당 원문 절을 기준으로 합니다. 전체 영문 색인은 [MSCP Comprehensive Glossary](/mscp/specs/MSCP_Glossary/)를 참고하십시오.

## 핵심 개념

| 용어 | 뜻 | 혼동하지 말아야 할 점 |
|------|----|----------------------|
| 최소 자기의식 프로토콜(MSCP) | 에이전트의 자기 상태 예측·비교·갱신을 제어하는 실험적 프로토콜 | 명칭이 주관적 의식이나 AGI의 달성을 뜻하지 않음 |
| 구조적 자기인식 | 자신의 상태와 변화를 모델링하고 제어하는 공학적 속성 | 현상적 의식과 구분 |
| 자기 모델 $M_t$ | 자료형과 스키마 버전이 명시된 자기 상태 기록 | 하나의 고정 벡터일 필요는 없음 |
| 의미적 연속성 | 버전이 호환되는 표현에서 자기 상태의 의미 변화가 제약을 충족하는지 | 해시의 일치 여부만으로 판단하지 않음 |
| 무결성과 변경 이력 | 기록이 변조되지 않았고 유효한 상태에서 이어졌는지 검증하는 속성 | 의미적 유사도와 구분 |
| 예측 기반 실행 승인 | 실행 전에 예측, 정책, 불확실성, 위험, 관측 가능성, 복구 가능성, 예산을 함께 검사하는 절차 | 저장된 예측 기록만으로 실행을 허용하지 않음 |
| 갱신량 제한 | 필드별·전체·유한 기간의 변화량 한계를 적용하는 규칙 | 한 단계의 상한이 장기 수렴을 뜻하지 않음 |
| 불변 조건 | 모든 승인된 상태 전이가 충족해야 하는 조건 | 검증기의 무결성과 우회 경로 부재 등의 가정이 필요 |
| 종합 조절 위험 $R(t)$ | 정규화한 위험 신호를 가중 합산한 진단 지수 | 자동으로 리아프노프 함수가 되지 않음 |
| 메타 조절 상태 지수(MRHI) | 여러 관측 신호를 요약한 정책 입력 | 단독으로 권한을 부여하거나 안전을 인증하지 않음 |
| 운영 조절 벡터 $A_t$ | 우선순위나 관측 자원을 조절하는 보조 신호 | 감정의 존재나 외부 중단 거부 권한을 뜻하지 않음 |
| 단계적 기능 축소 | 자원이 부족할 때 핵심 안전 기능을 유지하면서 기능을 줄이는 동작 | 필수 안전 자원도 부족하면 자율 동작을 중지 |
| 항상성 안전 | 검증된 운영 범위 이탈을 감지하고 정책 안에서 복구하는 기능 | 시스템의 존속 자체보다 외부 통제와 복구 가능성을 우선 |

## 자주 사용하는 약어

| 약어 | 한국어 설명 | 주의 사항 |
|------|-------------|-----------|
| PLA | 점진적 언어 자율성 | 입력 해석부터 문장 실현·재시도·실패 처리까지 LLM 없는 언어 이해·합성; LLM 생성물을 독립적으로 승인하는 구조와 구분 |
| LAG | 언어 자율성 갭 | 과거의 선택적 외부 비교 지표; PLA의 정의·실행 의존성·필수 평가가 아님 |
| CDTS | 교차 도메인 전이 점수 | 평가 도메인, 비교 기준, 분모의 유효성을 명시 |
| GPI | 목표 진척 또는 지속 지수 | 문서마다 명칭과 측정 구간을 확인 |
| BGSS | 제한된 성장의 안전·안정성 점수 | 평균이 필수 안전 조건을 대신하지 않음 |
| ICS | 정체성 연속성의 코사인 유사도 진단값 | 크기 변화, 필드별 하한, 변경 이력, 외부 통제 수용성은 별도 검사 |
| ASS | 자율성 안정성 점수 | 목표 구간과 동결 기준은 서로 다름 |
| AMS / SMS | 자율성 / 전략 성숙도 점수 | 종합 점수가 높아도 필수 조건의 실패를 상쇄하지 못함 |
| OMI | 전체 성숙도 지수 | 필수 조건별 평가 뒤에 보고하는 진단용 기하평균 |
| MVC | 최소 인지 기능 기준 | 연구용 기준값을 보편적인 운영 상수로 해석하지 않음 |

## 표기와 번역 주의

- $M_t$는 자기 모델 기록, $I(t)$는 정체성과 관련된 특징 표현입니다. 둘을 항상 같은 것으로 취급하지 않습니다.
- $R(t)$는 L3의 종합 위험 지수이고, L5의 $R$은 회복력 지수입니다. 정의한 문맥을 확인합니다.
- AS는 L4의 적응 속도와 L4.9의 자율성 안정성 하위 점수에 사용됩니다.
- EU는 과거의 환경 불확실성 요약과 SMS의 오류·불확실성 처리 점수에 사용됩니다. 현재 L4.8의 핵심 정의는 의사결정별 불확실성 벡터입니다.
- 해시 불일치, 의미적 표류, 관측 누락은 서로 다른 사건입니다.
- 임계값과 관측 구간은 평가 조건과 함께 읽어야 하며, 누락된 근거를 성공이나 0으로 간주하지 않습니다.
