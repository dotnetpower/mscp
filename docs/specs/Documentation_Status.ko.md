# 문서 상태와 검증 기준

**문서 검토 기준일: 2026-11-03.** 문서를 정비한 날짜이며, 새로운 실험의 수행일이나 참조 구현의 인증일을 뜻하지 않습니다.

## 개정 이력

| 버전 | 날짜 | 설명 |
|------|------|------|
| 0.1.0 | 2026-11-03 | 첫 이력 기록. PLA의 비LLM 언어 처리 경계를 명확히 하고 문서 회귀 검사와 실제 구현의 의존성 검증을 구분했습니다. |

## 공개 문서가 설명하는 범위

MSCP는 에이전트가 자신의 상태 변화를 표현하고 예측하며 제어하는 **구조적 자기인식**을 위한 실험적 아키텍처와 프로토콜입니다. 프로젝트 명칭이 주관적 경험, 현상적 의식, AGI 달성을 뜻하지는 않습니다. L4.5·L4.8·L4.9는 중간 연구 단계이며, L6는 구현 목표가 아니라 이론적으로 논의하는 경계입니다.

| 범위 | 설계 문서 | 공개된 구현 근거 | 단계 충족 여부의 검증 근거 |
|------|:---------:|------------------|--------------------------|
| L1–L2 | 있음 | 이 저장소의 교육용 CLI 예제 | 예제는 메커니즘을 설명하며 보편적인 단계 인증을 제공하지 않음 |
| L3–L4.5 | 있음 | 연구 문서에서 설명한 참조 프로토타입 | 이 문서만으로 독립적인 단계 검증이 성립하지 않음 |
| L4.8–L5 | 연구 기준 | 내부 구현의 세부 사항은 공개 명세의 범위 밖 | 독립적으로 검증된 단계 달성을 주장하지 않음 |
| L6 | 이론적 논의 | 여기서 확인된 구현 근거 없음 | 의식이나 AGI의 달성을 주장하지 않음 |

진척도를 설명할 때는 다음 네 상태를 구분합니다.

- **설계됨:** 동작 계약이나 아키텍처가 명시되어 있습니다.
- **구현됨:** 범위가 정해진 구현에서 해당 메커니즘의 존재를 확인했습니다.
- **테스트됨:** 특정 코드 버전과 환경에서 명시된 테스트가 통과했습니다.
- **실험적으로 검증됨:** 사전 등록한 평가의 데이터, 비교 기준, 불확실성, 한계, 결과를 보고했습니다.

이 상태들은 서로 대체할 수 없습니다. 코드가 있거나 테스트가 통과하거나 종합 점수가 높다는 이유만으로 단계의 모든 진입 조건을 충족했다고 볼 수는 없습니다. 공개되지 않은 근거는 내부 구현 활동으로 추정하지 않고 **공개적으로 입증되지 않음**으로 표시합니다.

## 수학적 주장을 읽는 기준

정의와 가정은 각 레벨 문서의 해당 절을 기준으로 합니다. 용어집과 홈은 이를 요약한 문서입니다.

- 갱신량 제한은 한 단계 또는 유한한 기간의 변화량을 제한합니다. 수렴이나 전체 수명에 걸친 표류의 상한을 뜻하지는 않습니다.
- 종합 모니터링 지수가 자동으로 리아프노프 함수가 되는 것은 아닙니다. 안정성 정리에는 동역학, 평형점, 가정, 적절한 감소 조건이 필요합니다.
- 해시는 정규화된 표현의 무결성과 변경 이력을 검증합니다. 의미적 유사도를 측정하지는 않습니다.
- 엔트로피 차이와 출력 분포의 차이는 진단 지표이지, 자율성이나 독립적인 승인 권한의 증명이 아닙니다.
- 산술평균이나 기하평균이 높아도 필수 조건의 실패를 상쇄할 수는 없습니다.
- 수치 임계값, 가중치, 예산, 관측 구간은 보정·평가 조건이 명시되지 않았다면 연구용 예시로 읽어야 합니다.
- 불변 조건의 보존은 모든 실행 경로의 검증, 초기 상태의 유효성, 정책·검증기·복구 기록의 무결성을 전제로 합니다. 모든 배포 환경의 실패까지 포괄하는 보장은 아닙니다.

## PLA의 비LLM 언어 처리 경계

PLA는 전처리, 계획, 문장 실현, 재작성, 순위 결정, 재시도, 대체 경로까지 외부와 로컬 LLM 추론을 사용하지 않는 언어 이해·합성을 뜻합니다. LLM 초안을 독립적으로 승인해도 PLA가 되는 것은 아닙니다. MSCP 일반 원칙의 모델 제안 허용은 다른 에이전트 설계에 관한 설명이지 이 경계의 예외가 아닙니다.

구현 근거를 제시하려면 의존성을 검토하고, 외부·로컬 LLM 진입점을 차단한 상태에서 호출 횟수를 기록하며 실패 경로를 포함한 대표 사례를 시험해야 합니다. 의미 보존, 문법, 접지, 처리 범위, 지원하지 않는 입력의 명시적인 처리도 별도로 평가합니다. 좁은 표본에서 호출이 0이었다는 관측만으로 완전한 독립성을 입증할 수는 없습니다.

선택적인 외부 LAG나 젠슨-섀넌 비교는 실행 의존성이나 단계 판정 조건이 아닙니다. 이 저장소의 문서 검사는 작성된 계약을 점검하며 비공개 구현을 검증하는 것은 아닙니다.

## 공개 정보와 비공개 정보의 경계

공개 승인을 받은 동작 계약, 가정, 평가 방법, 한계를 문서화합니다. 비공개 구현 위치와 식별자, 자격 증명, 운영 로그, 원본 평가 데이터, 배포 설정, 내부 보정값, 미공개 역량 주장은 이 저장소에 포함하지 않습니다.

비공개 소스나 변경 기록을 복사하지 않고, 공개 가능한 요약을 바탕으로 문서를 작성합니다. 게시 전에는 본문뿐 아니라 그림, 예제, 생성된 HTML, 저장소 변경 사항도 검토합니다. 자동 검사는 이 검토를 돕지만, 기밀 정보가 없음을 증명하지는 못합니다.

## 한국어 용어 기준

| 영어 | 한국어 | 사용 기준 |
|------|--------|-----------|
| Minimal Self-Consciousness Protocol | 최소 자기의식 프로토콜 | 프로젝트 이름 |
| Structural self-awareness | 구조적 자기인식 | 주관적 의식과 구분하는 공학적 속성 |
| Self-model | 자기 모델 | 에이전트를 구조적으로 표현한 모델 |
| Self-modification | 자기 수정 | 명시적인 제약 아래 승인한 변경 |
| Invariant | 불변 조건 | 항상 충족해야 하는 조건 |
| Integrity / semantic continuity | 무결성 / 의미적 연속성 | 서로 다른 속성이므로 혼용하지 않음 |
| Graceful degradation | 핵심 안전 기능을 유지하는 단계적 기능 축소 | 자원이 부족할 때 기능 범위를 줄이는 동작 |
| Persisted prediction | 저장된 예측 기록 | 실행 전에 기록한 예측 |
| LLM-free language synthesis | LLM 없는 언어 합성 | PLA 내부에서 LLM 생성·재작성·순위 결정·대체 경로를 사용하지 않음 |

## 문서 검증

저장소 루트에서 실행합니다.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-docs.txt
npm ci
.venv/bin/python -m unittest discover -s scripts -p 'test_*.py'
.venv/bin/mkdocs build --strict
.venv/bin/python scripts/check_docs.py
.venv/bin/mkdocs serve --dev-addr 127.0.0.1:8000
```

검사기는 생성된 페이지의 내부 링크와 앵커, 설정된 KaTeX 버전에서의 수식 처리, 한·영 핵심 수식의 대응 관계, PLA의 두 비LLM 도식, 수정한 진단 지표의 수치 회귀 사례를 확인합니다. PLA 검사는 문서의 일관성을 확인하는 것이지 실제 추론 동작을 검증하는 것은 아닙니다. 이 검사가 프로토콜의 안전성이나 실험 성능을 입증하지는 않습니다.

브라우저에서는 양쪽 언어, 넓은 화면과 좁은 화면, 페이지 간 즉시 이동을 확인합니다. 페이지 초기화 후 수식 오류 표시나 렌더링되지 않은 수식이 남지 않아야 합니다.
